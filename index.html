Hak Cipta & Atribusi Aset

Platform Inside You menggabungkan kurasi medis interaktif, model 3D terbuka, dan kecerdasan buatan. Kami menghargai dan mematuhi lisensi terbuka para kontributor berikut:

BodyParts3D 4.0 (Geometry & Taxonomy)

CC BY 4.0

Struktur poligon dan relasi anatomis Part-Of / Is-A bersumber dari Database Center for Life Science (DBCLS), Jepang.

lifesciencedb.jp/bp3d

OpenStax Anatomy & Physiology 2e

CC BY 4.0

Rujukan materi kurikulum teks, fungsi fisiologis, dan terminologi medis bersumber dari OpenStax karya J. Gordon Betts et al.

openstax.org

Z-Anatomy & Open 3D Community

CC BY-SA 4.0

Model 3D dasar dan visualisasi organ spesifik diadaptasi dari repositori anatomi terbuka Z-Anatomy project.

z-anatomy.net

Athena Engine & Audio Interface

Proprietary / Web API

Didukung oleh arsitektur model Google Gemini API untuk penalaran anatomi dan W3C Web Audio API untuk sintesis haptik taktil.
